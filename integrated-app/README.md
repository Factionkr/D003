## 🚀 빠른 시작 방법 (Quick Start)

### 방법 1. 원클릭 실행 (가장 추천)
`c:\Project\D003\integrated-app\start.bat` 파일을 더블 클릭하면 서버 구동과 함께 기본 브라우저가 자동으로 열립니다.

또는 PowerShell 터미널에서:
```powershell
cd c:\Project\D003\integrated-app
.\start.ps1
```

### 방법 2. Node.js 직접 실행
```bash
cd c:\Project\D003\integrated-app
node server.js
```
실행 후 웹 브라우저에서 `http://localhost:3000` 접속

### 방법 3. 브라우저로 직접 열기 (서버 없이 바로 실행)
별도의 서버 실행 없이도 `c:\Project\D003\integrated-app\public\index.html` 파일을 더블 클릭하여 크롬/엣지/웨일 등 웹 브라우저에서 바로 사용하실 수 있습니다. (로컬 스토리지 기반 전 기능 100% 작동)

## 📱 주요 화면 및 기능 안내

1. **대시보드 (Dashboard)**
   - 오늘 날씨 및 현재 체감온도 기반 기온 스타일링 요약
   - 오늘 일정에 따른 AI 1순위 추천 코디 하이라이트 및 매칭 점수 확인
   - 원클릭 가상 피팅 및 OOTD 빠른 저장
2. **체형 분석 랩 (D003-1)**
   - 실시간 2D 골격 와이어프레임 랜드마크 비주얼라이저
   - 어깨, 허리, 골반 너비 슬라이더 조절 시 실시간 5대 체형 판정
   - 체형별 최적 스타일링 조언, 추천/주의 의류 가이드 제공
3. **스마트 디지털 옷장 (D003-4)**
   - 기본 18벌의 다채로운 사계절 의류 데이터 탑재
   - 카테고리별(상의, 하의, 아우터, 신발, 가방, 즐겨찾기) 탭 필터링
   - "+ 새 의류 아이템 등록" 팝업을 통한 간편한 신규 의류 등록
4. **AI 코디 추천 & 스코어링 (D003-5 & D003-7)**
   - 일정 유형(Occasion) 선택 및 격식(Formality) 슬라이더 조절
   - 1차 하드 필터링 통과 후 5대 가중치(TPO 30%, 날씨 25%, 체형 20%, 취향 15%, 컬러 10%) 채점
   - AI 스타일리스트 정밀 리포트 및 총평 확인 후 가상 피팅룸으로 바로 전달
5. **AI 가상 피팅 스튜디오 (D003-6 & D003-8)**
   - 추천받은 코디의 착장 레이어(이너 -> 아우터 -> 하의 -> 슈즈) 순서 확인
   - VTON 모델(IDM-VTON, CatVTON, VITON-HD) 선택
   - 4단계 파이프라인(포즈 분석 -> 세그멘테이션 -> 워핑 -> 디퓨전) 실시간 렌더링 프로그레스 바 제공
6. **OOTD 캘린더 & 통계 (D003-9)**
   - 월별 코디 달력 그리드에 착용 썸네일과 만족도 별점 표시
   - 이번 달 평균 만족도, 최다 착용 TOP 3 아이템, 카테고리별 착용 비중 통계 리포트
7. **프로필 & 온보딩 (D003-2)**
   - 사용자 닉네임, 성별, 거주 도시(날씨 연동), 직업군, 퍼스널 컬러 및 선호 스타일 설정
